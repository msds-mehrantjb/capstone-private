Architecture Interpretation (important)

Your project is a monorepo containing both backend and frontend

Capstone-main
│
├── app        ← Backend (FastAPI + Agent + RAG + LLM)
│
├── data       ← Raw input data, metadata, dashboard JSON
│
└── app/src    ← Frontend React application

Backend Responsibilities

app/api/              → FastAPI routes
app/agent/            → Agent runtime (LangGraph orchestration)
app/rag/              → Chroma vector DB interface
app/llm/              → Ollama / local LLM integration
app/reports/          → Report generation
app/chroma_db/        → Persistent vector database

Frontend Responsibilities

app/src/pages/
    Dashboard.tsx     → Your dashboard page

app/src/components/
    Dashboard widgets

app/src/api/
    API client calls

Data Location (critical for dashboard)
Your dashboard JSON is located at:
Capstone-main/data/raw/Dashboard.json


NOT inside app/

Correct Path Resolution from FastAPI
Since FastAPI runs from:

Capstone-main/app/

Your system is correctly structured as:
Frontend (React)

            ↓
