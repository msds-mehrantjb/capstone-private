# 2026 Working Audit Data

Live working state for the 2026 audit workflow.

Key files include `SystemStatus.json`, asset inventory/details, threat/vulnerability results, controls/posture results, risk analysis/treatment, Annex A/SoA, action-plan and monitoring data, AI/ML KPI/dashboard data, and user behavior activity.

## Subfolders

- `evidence/` — action/implementation evidence uploads.
- `monitoring_evidence/` — monitoring evidence uploads.
- `chroma_control_to_cve/` — generated persistent Chroma index for control/CVE retrieval.

These files are application-managed and may change during normal workflow execution.
