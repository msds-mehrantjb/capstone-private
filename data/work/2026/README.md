# `data/work/2026`

This folder is the active working dataset for the 2026 audit run.

It contains the JSON files that the app reads and updates while you move through the ISO 27001 workflow. In general:

- `v0` baseline drafts live in `data/raw`
- submitted and working records for the 2026 run live here
- most files in this folder are generated, rebuilt, or updated by page commands inside the app

## Main workflow files

- `SystemStatus.json`  
  Tracks page-by-page lifecycle status for the current audit run.

- `AssetInventory.json`  
  Current asset inventory and CIA results.

- `AssetVulnerabilitiesThreats.json`  
  Threat and vulnerability results per host.

- `ExistingControlsPostures.json`  
  Existing controls and posture assessment results.

- `RiskAnalysis.json`  
  Risk analysis results, including user activity behavior risk rows.

- `RiskEvaluationTreatment.json`  
  Evaluation and treatment decisions for analyzed risks.

- `AnnexA_SoA.json`  
  Annex A applicability and Statement of Applicability working file.

- `ActionPlanImplementation.json`  
  Treatment implementation plan, host-level evidence, and related action records.

- `MonitoringImprovement.json`  
  Monitoring and improvement plan for monitored items and follow-up evidence.

## Guide files

- `ActionImplementationGuides.json`  
  Generated implementation guides linked to Action Plan / Implementation evidence.

- `MonitoringImplementationGuides.json`  
  Generated monitoring guides linked to Monitoring & Improvement evidence.

## AI / ML dashboard files

- `AIMLKPIInputs.json`  
  Raw KPI telemetry and counters used to compute AI/ML dashboard metrics.

- `AIMLDashboard.json`  
  Historical dashboard snapshots. The latest snapshot is used by the AI/ML page.

## Supporting data files

- `AssetDetails.json`  
  Detailed asset metadata, including behavior-related fallback fields used by the behavior collection flow.

- `DockerAssetInventory.json`  
  Docker lab discovery details used during infrastructure exploration.

- `OU.json`  
  Organizational unit data used to support scope and environment context.

- `UserBehaviorActivity.json`  
  Aggregated workstation behavior activity used by Risk Analysis and AI/ML KPIs.

- `VMControlsPostures.json`  
  VM-oriented controls posture helper data.

## Supporting folders

- `chroma_control_to_cve/`  
  Chroma/RAG working data used by control-to-vulnerability retrieval flows.

- `evidence/`  
  Stored evidence artifacts referenced by Action Plan / Implementation.

- `monitoring_evidence/`  
  Stored evidence artifacts referenced by Monitoring & Improvement.

## Notes

- Do not manually rename these files unless you also update the code that reads them.
- Some files are rebuilt by submit/reset flows. Manual edits can be overwritten.
- If a page looks out of sync, check whether its source file in this folder was regenerated by a previous command.
