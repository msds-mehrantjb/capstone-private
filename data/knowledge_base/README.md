# Knowledge Base

Curated reference datasets used by RAG, role/CIA inference, vulnerability-to-control mapping, and audit recommendations.

Examples include:

- ISO/IEC 27002:2022 control data
- vulnerability/control mapping JSON
- server/workstation CIA and role-detection datasets
- categorized Windows software data

Treat these files as reference sources. When changing a dataset, rebuild or refresh dependent embeddings/indexes as required by `app/rag/`.
