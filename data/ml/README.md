# Machine Learning Data and Utilities

Training datasets, preprocessing utilities, vulnerability datasets, embedding artifacts, and ML models used by the application.

## Notable contents

- role-prediction training datasets
- user-behavior training data and scripts
- CVE / known-exploited-vulnerability datasets
- local embedding artifacts
- `models/` — serialized trained model files and metadata

Large files in this directory may be expensive to regenerate. Keep training inputs and model provenance synchronized.
